# Electricity-Demand-Forecasting

We claim that state-space models (MambaTS) can achieve comparable or better electricity-demand forecasting accuracy than Transformer-based time-series foundation models (TimesFM-3) while offering greater computational efficiency, particularly at longer input sequence lengths. We will test this claim by comparing forecasting accuracy (MAE and RMSE) and computational efficiency (training time, inference time, and GPU usage) across multiple temporal input scales using UK National Grid half-hourly electricity demand data (2009–2024).


This repo is for a forecasting project comparing state-space and transformer based models
